# Personal Task Manager

A simple Personal Task Manager developed using Laravel.

## Project Description

The Personal Task Manager allows users to create, view, edit, update, and delete tasks.

Users can also set the status of a task as Pending or Completed and assign a due date.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Task Status
- Pending and Completed Status
- Due Date
- Responsive User Interface

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- Git
- GitHub

## Database

The system uses MySQL.

### Tasks Table

| Field | Description |
|---|---|
| id | Task ID |
| task_name | Name of the task |
| description | Task details |
| status | Pending or Completed |
| due_date | Task deadline |
| created_at | Creation date |
| updated_at | Last update date |
